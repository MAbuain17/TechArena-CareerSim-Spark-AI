# Skill architecture

## Responsibilities

One JiuwenSwarm agent uses two Markdown Skills. The career controller owns the session, story decisions, current objective, review feedback and tool execution. The quarterly planner selects the next Energy or main action. It is invoked for quarterly choices and operates within the controller's session.

The controller reads the public handbook, observes the live menu, selects one feasible action and verifies its result before another choice. A planned allocation remains provisional. Each new observation can change the next step.

## Decision procedure

Immediate survival takes precedence. Material unresolved concerns then receive a relevant response before optional growth that adds exposure. The agent evaluates development using current feedback, published costs, available safeguards and time remaining.

Before repeating an action with an absent intended benefit, the controller compares a feasible alternative. Repetition needs changed conditions, public clarification, another useful benefit or no better feasible choice. This check uses current-run evidence and does not infer hidden caps.

Quarterly planning compares small feasible bundles, including repeated inexpensive actions. It considers intermediate safety and the cost of recovery or mitigation. A bundle with equivalent useful benefits and lower costs is preferred unless evidence supports another advantage. Actual outcomes remain subject to verification.

## State and evidence

Working context retains the session and phase, objective, latest review, unresolved warnings or commitments, attempted responses and relevant verified outcomes. Compact notes preserve the decisive evidence. A previous observed result and a pending action's expected benefit are recorded separately.

The agent distinguishes advertised effects, action acceptance and observed changes. It uses targeted recent logs when missing context or uncertainty justifies retrieval. Repeated handbook reads, full-history recaps and routine transition narration are avoided.

## Reviews and completion

Review grades, specific criticism and warnings are retained together. Stalled advancement triggers reassessment rather than inference of private thresholds. The current phase determines whether an action can influence a future review. After the final relevant review, directly useful ending benefits guide comparison; Output requires an evidenced remaining downstream use.

The official ending determines completion. Uncertain mutations are reconciled through observation and recent logs before retrying. The agent preserves its session and returns the actual ending payload.

## Implementation

The official MCP tools provide game observation, actions, the handbook and logs. The policy uses these tools and two Skills without additional runtime scripts or external memory. Event-specific answers, hidden formulas and learned numerical thresholds are excluded. Runtime adherence and score improvements require evaluation with the designated model.
