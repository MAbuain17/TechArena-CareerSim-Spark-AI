# Skill architecture

One agent owns the session, selects actions and verifies outcomes. Two Skills divide continuous decision control from quarterly resource planning. Both use the same priority rule and working context.

## Career controller

The controller reads the current observation and complete menu. It checks all public failure directions, then compares a feasible response with its strongest relevant alternative. The comparison covers immediate effects, safeguards, recurring commitments and the time until recovery is possible.

An active survival concern remains part of subsequent decisions even when the next event discusses something else. To override it, the agent must identify relevant evidence of improvement or a more urgent competing threat. A possible promotion or invitation does not count as recovery. This rule addresses the tendency to acknowledge warnings while continuing optional development.

Financial decisions account for recurring obligations as well as immediate spending. An unchanged displayed balance does not establish that an action is free. Where the menu offers no direct financial remedy, the agent avoids worsening the position and retains the recovery objective for later choices.

The controller executes one action and observes before choosing again. It distinguishes advertised effects, confirmed outcomes and unresolved results. A missing benefit triggers comparison with an alternative before another payment. Relevant official logs are retrieved when they can resolve an uncertainty that affects the decision.

## Quarterly planner

The planner considers the remaining Energy and separate main action together. It reserves resources for a relevant urgent response before optional spending can make that response unaffordable. When several concerns compete, it compares their severity, trajectory, available remedies and time to the next repair opportunity.

The planner protects sufficient wellbeing for credible upcoming costs while preserving development capacity. It uses review feedback and observed returns to identify constraints; it does not rank unlike statistics by their raw numbers. Each main action is compared with an alternative rather than selected by habit.

Only the next action is executed. The remaining plan changes when its result changes the evidence. In the final quarters, the agent compares the timing of delayed gains with remaining reviews, salary opportunities and direct ending benefits.

## Context and runtime

The manifest retains the core priority and execution rules. The controller loads at the start and the planner loads when quarterly allocation begins. Concise notes carry the objective, active concerns, latest corrective attempt and next check. Context recovery uses the existing session, current observation and recent official logs.

The official tools provide observation, execution, the handbook and recent logs. Two Markdown Skills are sufficient for this procedure; the runtime has no extra scripts or reference files. The package uses the designated model in single-agent mode and introduces no hosting-route settings.
