# Six-Skill decision architecture

One agent owns the session. The Skills divide responsibilities without creating separate agents or independent plans.

| Skill | Responsibility |
| --- | --- |
| session-state | Interpret the current phase, verify outcomes and retain recoverable evidence. |
| choice-evaluation | Compare monthly options by consequences, safeguards and commitments. |
| survival-response | Respond to financial, organisational, wellbeing and performance threats. |
| quarterly-portfolio | Compare complete feasible uses of Energy and the separate main action. |
| advancement-strategy | Direct sustained delivery, capability and relationships using review feedback. |
| finish-and-score | Compare delayed payoffs and direct ending benefits over the remaining horizon. |

The first four continuous-control Skills load at session start. The quarterly and ending Skills load when their decisions become relevant. The manifest names their responsibilities and retains the execution contract. Skills are reused while available rather than repeatedly loaded.

The agent executes one current-menu choice, observes and updates the plan. Its notes preserve objectives, unresolved concerns, commitments and confirmed outcomes. Recovery uses the existing session and recent official logs.

The design uses Markdown instructions and the official game tools. It introduces no extra runtime scripts, external memory, model routing or multi-agent execution. Skill count separates decision responsibilities; it is not treated as evidence of higher performance.
